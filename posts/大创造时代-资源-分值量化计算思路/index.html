前言

《大创造时代》（Age of Innovation: A Terra Mystica Game）是 Terra Mystica 世界中的独立作品。若从玩家熟悉的机制来理解，也可以把它看作对《神秘大地》的一次大幅改造；它和《盖亚计划》的发展流程有不少相似之处，因此资源量化的思路也可以互相借鉴。

资源的价值会在轮次之间不断迭代，同时受到阶段性收益、行动窗口和玩家互动的影响，很难用一套公式精确描述。本文尝试把不同资源换算到一个近似的通用尺度，再据此比较它们在局中的实际价值。除非明确写作官方规则，下文的“赚”“亏”和强弱排序都指本文估值口径下的结果，不是游戏给出的固定定价。

资料说明｜游戏定位

Feuerland Spiele 官方页面将本作定义为 Terra Mystica 世界中的独立游戏；Capstone Games 官方规则书列出了本文涉及的建筑、资源、能力板和书行动。

记号

本文沿用我在《神秘大地》和《盖亚计划》中的旧缩写。它们在本作中分别对应：

  • 建筑：M = Workshop，TC = Guild，RL = School，AC = University，SH = Palace。
  • 资源：C = 金币，O = 工具，B = 书，P = 学者（Scholar，原稿也称祭司），K = 科学轨道格（Science display，原稿称信仰轨）。
  • 轮次：T1 表示第 1 轮，T6 表示第 6 轮，以此类推。

资源换算

金币和工具 C & O

本文按魔力行动的兑换关系，将每个金币记为 1 点通用资源，每个工具记为 3 点通用资源，即：

1c = 1 点通用资源
1o = 3 点通用资源

这只是后续比较所采用的基准单位。

科学轨道 K

科学轨道的收益相对直接：12k 可带来 8 魔力和 8 分；到达 9k 后有 3c 或 3 分的产出；每个轨道格还会在相应轮次带来约 1–1.5 点资源的一次性收益。

若按 T4 到达 9k 并取得 3 分计算，合计可近似写成：

1k = 1.5 资源 + 1.4 分

书 B

书的价值主要来自两个方向。

创新

创新（Innovation，原稿称“高级片”）是书的主要消耗渠道。若以 5/6/7 本书取得一个约值 18 分的创新作为基准，可以粗略取：

1b = 3.6 分

书行动

多余的书可以用于书行动。官方规则给出的行动数量如下；等号右侧的金币或分值换算是本文模型中的估值：

  • 1b = 5 魔 = 2.5c
  • 1b = 2k = 3c + 2.8 分
  • 2b = 6c，即 1b = 3c
  • 2b = 3c2o = 9c，即 1b = 4.5c
  • 2b = 2/4/6/8 分，即 1b = 1–4 分
  • 3b = 3 铲；铲通常用于前期，因此可计 1b = 3o = 9c

其中，比较容易产生正收益的行动有：

  1. 3b = 3 铲，即 1b = 9c
  2. 1b = 2k，即 1b = 3c + 2.8 分
  3. 2b = 升级 TC，即 1b = 4.5c

综合各项用途，每本书可以记为 5 点通用资源，与上面对具体书行动的估值并不冲突：1b = 5 魔只是保底兑换，在能够充分利用免费铲子或推进科学轨的局面下，书的实际收益可以明显更高。尤其在能够充分利用免费铲子的情况下，3b = 3 铲有很高的实际价值。

到了后期，如果已经具备 6b 换分的条件，再拆掉 6b 去做普通书行动，按本文口径几乎必亏。

资料说明｜书行动

官方英文规则书第 23 页列出的六种书行动分别是：1 本书换 5 魔力、1 本书前进 2 个科学轨道格、2 本书换 6 金币、2 本书免费把 Workshop 升为 Guild、2 本书按 Guild 数量每座得 2 分，以及 3 本书执行一次带 3 个免费铲子的 Terraform and Build。

学者 P

综合魔力转换和生产建筑的类型，每个学者粗略记为 5 点通用资源。

学者的用途也可以分为两类。

科学轨道

派出学者可以前进 3/2/1k，对应：

p = 4.5/3/1.5 资源 + 4.2/2.8/1.4 分

因此，前期可以配合回合奖励争取 3k 格；2k 格则更适合留到后期。若按牺牲学者换取轨道推进的口径计算，每个 k 也可以记为 2 点资源。

航海和掘地升级

航海与掘地更多承担功能性的硬门槛，需要在特定时间解锁，很难只用资源量准确表示。这类升级首先应服从整局的发展规划。

基准盘面

开局资源

本文选择一组具体开局作为基准：

  • 种族：以哥布林计算，12c + 1o + 2k = 19
  • 地形：以 Wasteland 计算，15c + 4o + 2b = 37
  • 通用起始资源：2m + 2o + 4 魔力，按本文口径折合 2×5 + 2×3 + 4×0.5 = 18（2 座开局 Workshop 各记 5 点资源，魔力每点记 0.5）
  • 每回合产出：1o + 特权片 6c = 9

前三项静态资源合计 74；计入 T1 的首轮产出 9 后，模型以 83 点资源作为第一轮行动阶段的起点，之后每轮继续产出 9 点资源。

终局资源

本文取以下终局盘面作为估值目标：

9m 2tc 3rl sh ac 3航 3铲 4p 3桥 24k

按本文的统一尺度展开：

9×5  2×14  3×28  32  23  3×9  3×13  4×5  3×3  24×2

合计 355 点资源。

终局分数

我当时参考了高分玩家 Sertuy 的对局表现，把 205 分作为玩家合理展开并争取第一名时的经验锚点。这个数字服务于下文的近似模型，不表示所有人数、地图和配置下的固定胜分线。

资源迭代转换率

模型把 T1 的 83 点资源和每轮 9 点持续产出，经过五次跨轮转换，近似映射到 T6 的 355 点资源与 205 分。

设每点资源每轮迭代后变为 x 点资源，并同时产生 y 分。资源侧满足：

\[83x^5 + 9(x^4 + x^3 + x^2 + x + 1) = 355\]

解得资源迭代转换率：

\[x \approx 1.27\]

在这套经验模型中，进一步取：

\[y \approx 0.19\]

因此，每点资源每轮近似迭代为 1.27 资源 + 0.19 分。T1 的 1 点资源到 T6 可以转化为 3.3 点资源与 1.62 分，前期资源的跨轮价值相当可观。

轮数 T1 T2 T3 T4 T5 T6
资源 1 1.27 1.61 2.04 2.60 3.30
分值 0 0.19 0.43 0.74 1.12 1.62

按照同一模型，吸魔的终局资源与净分值可以写成：

轮数 T1 T2 T3 T4 T5 T6
吸1 1.65+0.81 1.30+0.56 1.02+0.37 0.81+0.21 0.63+0.10 0.5+0
吸2 3.30+0.62 2.60+0.12 2.04-0.26 1.61-0.57    
吸3 4.95+0.43 3.90-0.32 3.06-0.89 2.42-1.35    
吸4 6.60+0.24 5.20-0.76 4.08-1.52      

表中把 5 点通用资源换 1 分作为终局清仓的保底口径。官方规则中的“5 金币 = 1 分”也只是一种亏损的终局兑换，并不代表资源在局中的实际价值；只要仍有建筑、能力板、书行动或回合计分窗口，资源通常可以实现更高的转化率。

为了估计局中资源换分的实际价值，本文采用 T6 仍能以 2o3c 完成一项 3 分转化的情形。按 1o = 3c 计算，这相当于 3c = 1 分；由此可得：

T1 的 1c ≈ T6 的 2.72 分

这不是官方的终局兑换规则，而是本文用于比较局中机会的边际价值。

由此可以得到吸魔的一般规律：T3 前尽可能在人堆里升级较高建筑，T3 后再蹭取小额魔力，是提高资源收益的一种思路。

各建筑收益对比

有了统一的资源尺度和跨轮转换关系，就可以比较不同建筑的资源转换率。表中的等值消耗、等值产出和转换比均沿用前文口径。

基础建筑 M TC RL AC SH
基础消耗 2c1o 3c2o 5c3o-3k 8c5o-3k 6c4o
等值消耗 5 9 14-6 23-6 18
资源产出 1o 2.5~3c 1p+1o1k 10+1o1k+5c 4魔+1o1k
等值产出 3 2.5 10 20 7
升级资源转换比 0.60 -0.06 0.54 0.43 0.25
从 M 升级转换比 - -0.06 0.30 0.37 0.15

按这套估值，前期建造便宜的 M 和 RL 是赚钱的；需要取得创新时可以建 AC。TC 在前期血亏。

大建筑对终局结构比较重要，因此即使即时转换率不高，在时机合适时仍应考虑建造。

铲子

扩 M 花费 1o 2o 3o
等值消耗 8 11 14
升级资源转换比 0.38 0.27 0.21

按本文模型，即使扩张一个 M 只需要 2o，资源转换率仍然不如建造 AC。

强弱分析

能力板

总体而言，T1、T2 选择资源产能、T3 以后逐渐转向得分，是这套模型下收益较高的节奏。实际扩张会被地形、距离和行动阶段卡住，因此仍要同时考虑资源平衡与扩张规划。

2c3 分产

把 2c + 3 分作为能力板之间的基础比较项。

1o1k 产

1o1k = 4.5c + 1.4 分

与 2c3 分产比较，寻找 2.5c = 1.6 分的临界回合，大致位于 T3–T4。由此判断：

T1：1o1k 产 ≥ 2c3 分产
T1 之后：2c3 分产 > 1o1k 产

1b1 魔产

1b1 魔 = 5.5c

与 1o1k 产比较，寻找 1c = 1.4 分的临界回合，大致位于 T3。由此判断：

T1：1b1 魔产 ≥ 1o1k 产
T1 之后：1o1k 产 > 1b1 魔产

4 魔行动

4 魔 = 2c，并附带当回合产出 2c

按本文口径，它严格弱于 1o1k 产，只适合必须补充魔力或能形成额外配合的局面。

双铲

即时 6o = 18c，T1 终局价值 = 59.47c + 29.18 分
即时 4o = 12c，T1 终局价值 = 39.65c + 19.60 分
T1 1o1k 产的终局价值 = 38.40c + 18.19 分
T1 1b1 魔产的终局价值 = 46.93c + 13.67 分

双铲在理论上多赚几分，但前期通常并不急需用 4o 连续铲两块地，因此和持续产能板的实际差距没有数字看上去那么大。

小结

在资源产出能力板中，T1 的排序为：

1b1 魔产 ≥ 1o1k 产 ≥ 2c3 分产

双铲也可以选择，几种能力板在 T1 的差距不大；T1 之后则只建议优先考虑 2c3 分产。

工具、科学轨、书和魔力都有很强的阶段性，最终选择仍应服务于整局的发展规划。

资料说明｜能力板与回合计分

官方英文规则书第 24 页列出了本文比较的能力板及回合计分板。规则只规定它们提供的资源和分数；不同轮次的强弱关系属于本文模型的分析结果。

书行动

1b = 5 魔

3 分 = 2.5c，大致在 T1–T3 可以兑换，T4 以后略亏。

1b = 2k

3 分 = 3c + 2.8 分。只要书仍足够取得创新，任何轮次都是不错的选择。

2b = 6c

3 分 = 3c，大致在 T1–T4 可以兑换，T5 以后略亏。

2b = 升级 TC

3 分 = 4.5c，大致在 T1–T4 可以兑换，T5 以后略亏。

2b = TC 数量分

3 分 = 1–4 分；当 TC 数量不少于 3 时可以考虑。

3b = 3 铲

前期可按 1b = 3o = 9c估值，非常赚钱；后期则可近似视为 3 分 = 1o = 3c，T5 以后略亏。

种族

鼹鼠

以下分析保留原稿所依据的鼹鼠派系板和当时的估值口径：

1o = 2 分容易成为刷分陷阱；若只考虑纯刷分，3c = 2 分要到 T5 以后才开始赚钱。

因此，前期的鼹鼠基本可以看作 1 航海；后期的种族技能通常也刷不到 10 分，价值更多体现在功能性。

比较有优势的用法，是在 T5、T6 出现 M 回合计分板时，配合 M 计分能力板在单轮集中爆铺。相应地，前期可以 RL 缩地为主，并兼顾工具产能。

版本说明｜鼹鼠

Feuerland Spiele 在 2024 年 9 月发布了官方派系调整，并从 v1.2 起纳入新版。新版鼹鼠的跳跃得分改为 2 + X，其中 X 为其他玩家人数。因此，本节保留的是旧版模型下的历史分析，不应直接当作当前 v1.2 的种族攻略。

结语

这套量化方法的作用，是把金币、工具、书、学者、科学轨和行动机会暂时放到同一尺度上，帮助判断一局之内的几个候选方案。它最能说明的是：越早获得、并且能够及时投入发展的资源，越有机会在后续轮次继续增值。

实际对局仍然包含阶段性奖励、地图位置、玩家互动和功能性门槛，不能只按表格机械决策。本文的数字更适合用来检查发展计划是否大致合理，而不是跨派系、跨地图给出唯一的建筑或能力板顺序。
