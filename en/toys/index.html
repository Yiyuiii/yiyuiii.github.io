Toys

A few lightweight interactions to open, try, and leave at any time.

Moegirlpedia character quiz Read an anonymized entry introduction and choose the character from four candidates.

Starting a round makes one request to the Moegirlpedia API for a random batch of text introductions and categories, then filters the round locally. The third party can see the request and your IP address. This site uses no cookies, persistent storage, tracking, or images.

Quick challenges

Color difference challenge Find the subtly different tile and see how far you can go.

Each set contains three questions. Get at least two right to move up one of 25 levels; otherwise you move down. A correct answer adds one point and a wrong answer subtracts one, so the score may be negative.

The scale runs from the maximum black–white digital difference to a one-code, one-channel sRGB difference. This is a visual game, not a color-vision test or medical assessment.

Random generators

Random password Generate a configurable random password in your browser.

The password is generated only in this page and is never sent, saved, or logged. A trusted password manager is still the better place to keep real account passwords.

Choose 8–128 characters; lengths below 16 are flagged as short.

Random numbers Generate one or more random results from an integer range.

Results are uniformly sampled integers from the inclusive range and are calculated only in this page.
