Artwork quiz (Cleveland Museum of Art) Choose the quiz direction and whether to show title, artist, or date.

Discovering this round's candidates on Moegirlpedia…

Guess in either direction between a museum card and a complete artwork; choose the formats and whether cards show the title, artist, or date.

Starting a round sends one small-batch GET to the Cleveland Museum of Art Open Access API, using a shallow random offset among CC0 landscape paintings with complete title, artist, date, and image data. “Museum card → image” loads four roughly 900px JPEGs from the official image CDN; “image → museum card” loads only the one image needed as the clue. It does not continue, refill the batch, or prefetch another round. The open collection may still include religious, mythological, or nonsexual human figures; text screening cannot exclude them completely. The museum and its service providers can see the requests and your IP address; the API can also see this site's Origin, while image requests do not send this page as a referrer. Responses stay only in this page's memory; this site uses no cookies or persistent storage for the game.

Anime protagonist quiz (AniList) Choose among three four-choice links between anime and their main characters.

Choose anime to main character, main character to anime, or co-main-character matching (all based on AniList's MAIN label)

Starting a round normally makes one browser CORS permission check and then one official GraphQL POST query to AniList. It selects one random page among the first 360 anime in popularity order and reads six titles with at most ten character relationships each; it never follows another page or retries automatically. AniList can see these requests, your IP address, and this site's Origin; no credentials are sent. The response stays only in this page's memory. The toy does not save the round or attempt, and it does not request cover art. The English page uses AniList's English or romanized display names; AniList's MAIN label usually covers protagonists or a core main cast and may apply to more than one character. All three formats use that relationship directly and do not judge screen time independently.

Formats Adjust
Enabled formats

Each round randomly uses an enabled format that the current response can turn into an unambiguous four-choice question.

Titles, character names, and MAIN/SUPPORTING relationships come from AniList. This site excludes entries carrying AniList's adult flag, the Ecchi/Hentai genres, several sensitive tags, and titles or character names caught by a local sensitive-term filter, and shows text only. AniList notes that its filters are not a universal content rating.

Quick challenges

Color difference challenge Find the subtly different tile and see how far you can go.

Find the different tile among sixteen. By default, lightness, chroma, and hue changes are balanced. Each set contains three questions: get at least two right to move up; otherwise you move down. A correct answer adds 1 and a wrong answer subtracts 1, so the score may be negative.

Colors stay within a moderate lightness range. Every difference is checked again after conversion to final 8-bit RGB. This local game sends and stores no result, and it is not a color-vision test or medical assessment.

Play settings Adjust
Quick presets
Changes to include

When several are enabled, each question uses one change; the game balances them instead of mixing axes in one tile.

Main hue range

The six names divide the continuous OKLCH hue wheel into equal 60° ranges. They are guides, not six fixed colors. In a hue question, the repeated tile stays in the selected range while the different tile may shift toward a neighboring hue.

Gray has no useful hue, so this option applies only to lightness changes.
