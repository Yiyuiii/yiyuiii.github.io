This is the less formal edge of the site: compact tools and experiments that
make a model, strategy, or workflow directly testable.

## Current experiments

- **[Solver for Turing Machine](https://github.com/Yiyuiii/solver4turingmachine)** —
  enumerates feasible answers for the board game and recommends informative
  queries.
- **[Simple ASR–LLM–TTS](https://github.com/Yiyuiii/simple_asr_llm_tts)** — a
  minimal voice-chat pipeline built from speech recognition, an
  OpenAI-compatible model endpoint, and speech synthesis.
- **Agent evaluation environments** — task designs and simulation interfaces
  for studying long-horizon Code Agent behavior.

## In development

I am interested in turning several research and writing artifacts into
interactive demos:

- a high-dimensional Bayesian-optimization benchmark browser;
- an agent-evaluation result explorer;
- strategy calculators for resource-conversion board games;
- a reusable collection of Gym-style decision environments.

Stable tools will remain linked from the main
[Projects]({{ '/projects/' | relative_url }}) page; early work lives here.
