# 《综合训练系统》主题与编排修订底稿（2026-08-25）

## 1. 用户当前目标

用户最新明确的目标是：保持适度、清晰且容易维护的肌肉轮廓，同时均衡发展力量与力量体重比、爆发力、局部肌耐力、心肺能力和动作与专项技能。歌唱、拳击、欧洲历史武术与滑雪继续作为未来专项约束，用来检验一般训练是否有用；它们不再与“外形”并列成五套需要同时铺满的计划。

本次修订先建立可审阅候选，不直接修改正式 `master`。用户完成主题审阅后，于 2026-08-26 明确授权候选按受保护流程提交、创建 PR、合并并发布；是否正式上线仍以对应 GitHub Actions 与 Pages 验收为准。

## 2. 文章主轴

公开稿应沿一条逻辑展开：

1. 先区分适度肌肉量、力量与力量体重比、爆发力、局部肌耐力、心肺能力和专项技能；首十二周不把真实 1RM 测试当作任务。
2. 再说明三次精简全身力量、两次渐进有氧和两次低疲劳爆发暴露分别服务什么结果。
3. 之后给出十二周推进、每周日程和动作执行。
4. 组数、余力次数（RIR）与组间休息只解释增肌／力量工作组怎样累计剂量，不扩张成整篇文章的唯一训练逻辑。
5. 24 个动作教学保留为动作库；主表只安排当前阶段真正需要的动作，其余进入可选、替换或专项恢复后的路径。

## 3. 内容删留

### 保留

- 四种强度标尺：增肌／力量、爆发／落地、动作控制、等长／搬运。
- 24 个动作的作用边界、强度标尺和进阶链。
- 徒手到可量化负重的器械采购闸门。
- 忙碌版、旅行版、专项恢复后的减量与替换原则。
- 蛋白质、恢复和医疗警示的最小必要边界。

### 压缩或移动

- 腹肌短期“变平”等问答式内容移出开篇和主阅读路径；腹部只在体型记录、躯干训练与专项减量边界中出现。
- 鸡蛋个数、逐餐时刻和训练后几十分钟的进食窗口不展开成饮食处方；正文只用一段说明全天蛋白、三餐可行和可选加餐，并澄清不能由体重推出鸡蛋数量。
- 赛艇经历不写成诊断案例；只保留渐进有氧、谈话测试和心血管警示。
- “最快出拳”只用来说明爆发力与专项技术的区别，不把空击当成通用增肌动作。

### 不采用

- 把 `2–3 RIR`、`90 秒休息`或约 `10 组/肌群/周`写成统一生理阈值。
- 把概念性的刺激／疲劳曲线当作实验测得曲线。
- 用单次组间掉次数直接诊断局部恢复不足。
- 为覆盖全部动作而让每次训练稳定超过可执行时长。

## 4. 周结构

起始周采用：

- 周一：低疲劳爆发 + 全身力量 A；
- 周二：低到中等强度有氧；
- 周三：全身力量 B；
- 周四：休息、散步或轻松活动；
- 周五：低疲劳爆发 + 全身力量 C；
- 周六：低到中等强度有氧；
- 周日：休息。

力量日各保留约 5–6 个主体动作，再按真实瓶颈放入 0–2 个附件。第 1–2 周每项只做两组并学习 RIR；第 3–4 周只给每天前两个主体动作增加第 3 组，恢复稳定后第 5–6 周再走向目标组数。有氧从 20–30 分钟逐步增加到 30–45 分钟，以能交谈、不能轻松唱歌且不会出现异常症状为强度边界；稳定完成至少四周后才可自愿把周六的一部分改成少量短间歇。两次专门有氧只有 60–90 分钟；若日常步行等活动没有补足，不能声称已经达到每周 150–300 分钟中等强度活动的公共健康参照。

## 5. 科学表述边界

- 多组训练用于累计周训练剂量；不存在“第三组开关”。
- RIR 表示距离规范动作力竭还有多少次，不等同于负重强度。建立期可先用约 `2–3 RIR`，多数后续工作组落在 `1–3 RIR`；这是一项可调起点。
- 组间休息用于保存下一组的负重、次数、活动范围与动作质量。复合动作约 2–4 分钟、孤立动作约 1–3 分钟只是实用起点。
- 约 `10 组/肌群/周`用于描述偏向最大增肌时的平均参考，不是最低有效量。综合体能计划从可恢复的较低端开始，再按记录增减。
- 首十二周的徒手与背包处方建立一般力量和力量体重比，不声称已经构成最大力量周期，也不安排独自测试真实 1RM。
- 力量与有氧并行平均可以共同进步。分开安排主要为了保存单次训练质量，不把特定间隔小时数写成硬要求。
- 肌肉酸、烧、充血、喘或次日酸痛都不能单独充当增肌剂量计。
- 远超预期的严重肌痛、深色尿、明显无力或异常疲劳是可分别出现的就医警示，不能要求读者等到多项同时发生。
