# 小玩意按首次展开加载

## 目标与公开行为

`/toys/` 与 `/en/toys/` 在初始响应中保留全部十一项组件的完整 HTML、说明、表单骨架、JSON 配置和 `noscript` 回退。折叠状态不加载任何游戏运行时；首次展开、直接访问片段 ID、站内搜索打开片段或其它脚本把对应 `details.open` 设为 `true` 时，才加载该项目需要的本站脚本。

展开三个外部数据问答只加载本站控制器，不请求第三方。萌娘百科、克利夫兰艺术博物馆和 AniList 的请求仍只能由各组件的明确“开始”动作发起。

## 固定映射与顺序

`_includes/toy-index.liquid` 为每个公开项目输出依赖 token，并输出带缓存版本的 token→本站 URL 清单。`assets/js/toy-loader.js` 同时冻结：

- 公开项目 ID→依赖 token 顺序；
- token→允许的绝对路径。

加载器拒绝未知项目、被修改的依赖串、非当前来源 URL、路径不一致和带片段的 URL，因此 DOM 数据不能选择任意脚本。具有前置依赖的项目严格串行加载，例如 AniList 先载入纯逻辑再载入界面控制器，本地挑战先载入共同随机接口。

每个 token 的 Promise 在页面生命周期内共享。成功资源不重复执行；失败的脚本节点和 Promise 会移除，项目显示双语错误与重试按钮，后续重试只重新请求未成功的资源。加载期间对应 `details` 暴露 `aria-busy="true"`，完成或失败后移除。

## 构建预算

`scripts/check_site.py` 对中英文生产 HTML 执行以下硬门禁：

- `toy-loader.js` 的 Terser 产物不超过 4,096 bytes；
- 初始 HTML 中全部同源外链 JavaScript 的原始文件大小合计不超过 15,360 bytes；
- 每个语言页面恰好引用一个加载器；
- 任何游戏运行时都不得作为初始 `<script src>` 出现；
- 所有初始同源脚本必须存在并使用绝对路径。

2026-08-07 M1 验证时，中文页初始同源 JavaScript 为 11,515 bytes，其中加载器为 3,232 bytes；后续以构建门禁的实时结果为准，不把本次数值当成长期固定值。

## 回归入口

`tests/browser/toy-loading.spec.mjs` 使用冷页面记录请求集合，覆盖：

- 折叠态零游戏运行时；
- 十一项逐项首次展开的精确新增脚本集合；
- 共享依赖在并发展开时只请求一次；
- 局部加载失败显示本地化错误，并能重试恢复；
- 哈希直达只加载声明的依赖链；
- 被修改的依赖串不能发起站外脚本请求；
- 仅展开外部问答时不请求第三方。

完整发布验收仍使用 `python scripts/validate.py --browser`，不能只运行聚焦用例。
