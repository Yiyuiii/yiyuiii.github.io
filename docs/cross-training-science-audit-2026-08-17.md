# 《综合训练系统》肌群与动作科学审计（2026-08-17）

## 1. 审计问题与结论

本次审计回答四个问题：每个肌群为什么进入计划；每个动作实际训练什么；应当用哪一种强度标尺；初学版本何时应进阶、负重、替换或删除。公开随笔仍是一份可执行的三日计划，本文件保存逐项依据和证据边界。

核心结论如下：

1. 原稿把大部分项目放进同一个“困难组／RIR”框架，无法正确描述爆发、动作控制、等长保持和搬运。修订后使用四种强度标尺。
2. 双脚自重提踵 `2 × 15–25` 只能作为熟悉动作的起点。若 25 次后仍有 4 次以上余力，应改为扶墙单腿版或可量化负重；继续堆低难度次数的边际价值很低。
3. 夹枕内收、俯卧撑加号、俯卧 Y–T–W 和死虫属于入门控制或容忍度练习。它们不自动计为目标肌群的增肌困难组，也不需要硬造“重型版”。
4. 胫骨前肌抬脚、前臂旋转和腕伸展对健康年轻人的直接长期证据有限。它们保留为低成本可选附件，并设删除条件。
5. 腘绳肌需要同时覆盖髋伸与膝屈功能。髋铰链负责前者，臀桥走步／以后滑动腿弯举负责后者；臀桥主要作为臀肌动作，不据此声称充分训练腘绳肌。
6. “初学到重度”应理解为每个必要动作家族都有持续增加刺激的路线。爆发和控制动作的高级阶段追求更快、更准或更长杠杆；只有增肌／力量动作和搬运必须逐步得到稳定外部负重。

## 2. 证据等级

| 等级 | 本审计中的含义 | 写作规则 |
|---|---|---|
| A | 与问题相符的系统综述、荟萃分析、立场声明，或多项直接纵向证据 | 可支撑计划级原则，同时说明适用范围 |
| B | 直接纵向研究或相邻动作家族证据，但样本、动作、周期或人群有限 | 可用于选择与进阶，避免宣称唯一或普遍最优 |
| C | 急性肌电／生物力学、临床或专项人群、机制推断 | 只说明合理用途与边界，不当作健康成人长期增肌证明 |
| 证据不足 | 未找到能直接回答当前健康年轻成人、当前动作和目标的证据 | 标成可选或实验项，以训练记录决定去留 |

证据等级评的是“某项资料能否回答本文的具体问题”，不是给动作永久排名。同一动作可以在一般抗阻训练原则上得到 A 级支持，在自身特有变式上只有 C 级证据。

## 3. 四种训练类型与强度标尺

| 类型 | 代表动作 | 记录什么 | 合格工作组的停止点 | 怎样进阶 |
|---|---|---|---|---|
| 增肌／力量 | 分腿蹲、负重髋铰链、划船、俯卧撑、侧平举、提踵 | 动作版本、负重、规范次数、RIR、活动范围 | 目标肌群成为限制因素；大多停在 RIR 1–3 | 同版本先加次数；连续两次到区间上限且仍有 RIR 2，再加最小负重或进入难一档版本 |
| 爆发／落地 | 侧向稳定落地、快速上推俯卧撑 | 距离或版本、每次速度、落地声音与稳定 | 速度、距离或落地质量首次明显下降前 | 先提高一致性，再小幅增加速度或距离；不靠疲劳和力竭进阶 |
| 动作控制 | 死虫、俯卧撑加号、Y–T–W、部分胫骨前肌抬脚 | 杠杆长度、活动范围、停顿、呼吸与代偿 | 目标姿势刚好能保持；代偿出现即停 | 增加杠杆、范围、精准度或轻阻力；动作已掌握且无独立收益时维持或删除 |
| 等长／搬运 | 侧桥、夹枕内收、帕洛夫推、手提行走 | 张力或负重、时间／距离、姿势、呼吸 | 姿势或呼吸即将失守前 | 在时间区间上端稳定后增加张力、负重或杠杆，不无限延长时间 |

所有类型都应记录疼痛、失控和恢复。RIR 只适合能按重复接近肌肉能力边界的动作；把 RIR 强套给落地、呼吸或低负荷动作控制会制造虚假的精确度。

## 5. 二十四个动作逐项审计

### 5.1 下肢与爆发

| ID | 作用与训练类型 | 初学 → 可持续进阶 | 升级／退出条件 | 证据判断与公开稿决策 |
|---|---|---|---|---|
| L1 侧向稳定落地 | 侧向减速、单腿稳定；爆发／落地 | 侧向迈步定住 → 小幅跨跳定住 → 在质量不变时小幅增加距离／速度 → 回归专项技术课 | 3 次／侧都安静、定住 2 秒、左右接近才升级；失稳或距离下降即停 | 一般功率原则 A，精确动作 C；保留，不计增肌组，不练到力竭 |
| L2 分腿蹲 | 股四头肌、臀大肌及内收肌协同；增肌／力量 | 扶墙浅幅 → 全范围原地分腿蹲 → 反向弓步 → 背包／哑铃负重 → 可选前脚抬高或保加利亚版 | `3 × 15/侧` 连续两次且 RIR ≥2 后加重量或难度 | 一般渐进抗阻 A，单双侧比较 A，精确变式 B；保留为主力膝主导动作 |
| L3 髋铰链 | 腘绳肌髋伸功能、臀大肌、竖脊肌；增肌／力量 | 徒手碰墙（教学）→ 背包 RDL → 支架式单腿 → 哑铃 RDL → 更重稳定负重 | 徒手碰墙不算工作组；`3 × 15` 且 RIR ≥2 后加重量 | 一般原则 A，动作家族 B；明确教学版与工作版的区别 |
| L4 臀桥 | 臀大肌直接髋伸；增肌／力量 | 双腿停顿 → 单腿 → 稳定负重臀桥 → 负重髋推 | `3 × 20` 后仍有 RIR ≥4，立即换单腿或负重，不再堆次数 | 深蹲与髋推都可增臀 B；保留，但明确它不充分覆盖腘绳肌 |
| L5 低台阶踏步 | 股四头肌、臀肌、单腿控制；增肌／力量 | 扶墙低台 → 更高但仍可控台阶 → 手持负重 → 重负荷踏步 | 下方脚持续蹬地、下台失控或台面不稳时退阶／改 L2；到 15 次且 RIR ≥2 后加负重 | 家族证据 B/C；作为第二单腿暴露，安全台面缺失时删除 |
| L6 臀桥走步 | 腘绳肌膝屈能力兼髋稳定；动作控制逐步转为增肌 | 短步走出 → 更长杠杆 → 双腿滑动腿弯举 → 单腿或可量化负荷腿弯举 | 骨盆下降或抽筋前停止；15 次仍轻松且动作稳定时换滑动腿弯举 | 膝屈训练家族 B，走步本身 C；保留其互补功能，不夸大精确变式 |
| L7 提踵 | 腓肠肌、比目鱼肌；增肌／力量 | 双脚地面熟悉 → 另一脚脚尖辅助的偏重单腿 → 扶墙单腿地面 → 安全台阶全范围单腿 → 单手稳定负重 → 需要时追加屈膝负重版 | 双脚 25 次后仍有 RIR ≥4，下一次即换偏重单腿或单腿；单腿 `2 × 20` 且 RIR ≥2 后加负重 | 站姿与坐姿直接小样本 B；原剂量偏轻，主表改为 `2 × 8–20/侧` |

## 7. 证据来源与如何使用

### 7.1 计划级原则

- [ACSM 2026 抗阻训练立场声明（PubMed）](https://pubmed.ncbi.nlm.nih.gov/41843416/)：用于频率、组数、负荷、全活动范围、功率与训练到失败的总体判断。
- [不同抗阻训练处方的网络荟萃分析](https://pubmed.ncbi.nlm.nih.gov/37414459/)：用于“多种处方都有效、较高负荷更利于力量、多组更利于增肌”的边界。
- [接近力竭与肌肥大的元回归](https://pubmed.ncbi.nlm.nih.gov/38970765/)与[力竭／非力竭荟萃分析](https://pubmed.ncbi.nlm.nih.gov/36334240/)：用于 RIR 只服务可重复负荷动作，且无需每组达到瞬时力竭。
- [全活动范围系统综述](https://pubmed.ncbi.nlm.nih.gov/34170576/)与[肌肉拉长位训练综述](https://pubmed.ncbi.nlm.nih.gov/41646176/)：支持优先可控全范围，同时不把拉长位局部次数写成普遍定律。
- [动作变化系统综述](https://pubmed.ncbi.nlm.nih.gov/35438660/)：用于有目的的动作变化及删除随机、冗余变式。
- [训练顺序系统综述](https://pubmed.ncbi.nlm.nih.gov/32077380/)：用于把优先力量动作排在前面；不声称顺序决定增肌。
- [增加次数与增加负重的纵向比较](https://pubmed.ncbi.nlm.nih.gov/36199287/)：支持双重进阶的两种路线。
- [单侧与双侧训练系统综述](https://pubmed.ncbi.nlm.nih.gov/39794667/)：用于肌肥大相近、力量具有测试特异性的边界。
- [降低训练剂量后的适应保留](https://pubmed.ncbi.nlm.nih.gov/21131862/)：用于建立后测试更低维护量，不用于保证个人最低剂量。
- [抗阻训练处方报告清单](https://pubmed.ncbi.nlm.nih.gov/35907047/)：用于强制记录负荷、次数、RIR、活动范围、节奏与动作类型。

### 7.2 动作与肌群专项资料

- [俯卧撑与低负荷卧推的八周比较](https://pmc.ncbi.nlm.nih.gov/articles/PMC5812864/)：18 名未训练男性的小样本，支持相近相对强度下俯卧撑可产生胸／肱三头适应；不能证明所有俯卧撑版本等同卧推。
- [站姿与坐姿提踵的十二周比较](https://pubmed.ncbi.nlm.nih.gov/38156065/)：14 名未训练成人的小样本；站姿对腓肠肌和全小腿增长更有利，比目鱼肌结果相近。
- [提踵在肌肉拉长区间训练的比较](https://pubmed.ncbi.nlm.nih.gov/37015016/)：42 名年轻女性；用于说明完整下降和拉长位值得保留，不据此删除全活动范围。
- [年轻成人双脚提踵重复能力参考](https://pmc.ncbi.nlm.nih.gov/articles/PMC5628365/)：其快速疲劳测试与本文慢速工作组不同，只用于提示健康年轻男性做 15–25 次双脚提踵可能远未接近能力边界。
- [足踝练习剂量报告范围综述](https://pubmed.ncbi.nlm.nih.gov/40178827/)：多数研究缺少可量化负荷，支持本文对小腿／胫骨前肌证据与剂量的谨慎处理。
- [肩胛俯卧撑加号肌电系统综述](https://pubmed.ncbi.nlm.nih.gov/31584855/)：支持前锯肌参与和稳定表面版本，证据性质为急性肌电。
- [侧平举哑铃与拉索的八周比较](https://pubmed.ncbi.nlm.nih.gov/40692697/)：24 名训练者的体内对照小样本，支持两种阻力都可用于三角肌中束增肌。
- [深蹲与髋推的臀肌增长比较](https://pubmed.ncbi.nlm.nih.gov/37461495/)与[臀大肌训练系统综述](https://pubmed.ncbi.nlm.nih.gov/40276368/)：支持多个髋／膝动作家族可增臀，并限制“臀桥充分训练腘绳肌”的推断。
- [膝屈离心动作的腘绳肌适应比较](https://pubmed.ncbi.nlm.nih.gov/38857522/)：支持保留膝屈家族，并承认适应具有动作特异性。
- [核心稳定训练与运动表现系统综述](https://pubmed.ncbi.nlm.nih.gov/22784233/)与[躯干训练系统综述](https://pubmed.ncbi.nlm.nih.gov/26589515/)：支持提高躯干能力，同时限制对专项迁移的承诺。
- [八周哥本哈根内收训练随机试验](https://pubmed.ncbi.nlm.nih.gov/26589483/)：U19 男足样本中提高髋内收离心力量；不能证明夹枕等长对普通成年人有相同效果。
- [击剑运动员前臂训练迁移研究](https://pubmed.ncbi.nlm.nih.gov/32013174/)：用于区分一般前臂能力与持剑技能迁移。

## 8. 尚不能从现有证据回答的问题

1. 靠墙胫骨前肌抬脚能否在健康、无症状年轻成人中带来有意义的长期肌肥大或专项表现改善。
2. 夹枕内收保持的实际张力不可量化，它在何种剂量下能超出动作熟悉与短期容忍度训练。
3. 水瓶腕伸展和旋前旋后对欧剑表现的净收益，以及它们在正式持剑训练恢复后的最佳周剂量。
4. 本文完整 A/B/C 组合对同一人的外形、维护成本、歌唱、拳击、欧剑和滑雪的联合长期效果。没有研究直接测试过这一整套组合。

因此，这些项目必须接受“删除也可能是正确进阶”的结果。保留条件是四周内至少出现一个可测变化：更高的可量化阻力、更长但仍在目标区间内的稳定时间、更好的动作一致性，或明确解决了实际爱好中的一般体能瓶颈。
