# 阳光背景与开关实施规格

## 展示边界

- 除双语 404 外，所有默认布局页面都从左上角头像圆心发出暖金色径向光晕与极淡静态光线；原左侧紫晶光晕被替换，右侧玉色光晕降低到 `0.03` 透明度。
- 光层由 CSS 渐变生成，在约 `58rem` 内淡出，不使用动画、滤镜、外部图片或字体，也不接收指针事件。它位于正文之后的负层级，不改变布局、滚动或焦点。
- 光源坐标由页眉 `68rem` 最大宽度、页边距与 `2.25rem` 头像尺寸共同计算；在 1280、390、320 px 及移动页眉换行时仍与头像圆心一致。

## 控件与隐私契约

- 太阳按钮位于搜索与语言切换之间，使用原生 `button`、`aria-pressed` 和中英文动作/状态文案；欢迎页第五条指引直接说明该按钮，不新增导航入口。
- 效果默认开启。唯一持久化键为 `yiyuiii.sunlight.v1`，值只写入 `on` 或 `off`；非法值按开启处理，不被静默改写。实现不使用 Cookie、访问记录、外部请求或其它追踪字段。
- `<head>` 中的最小内联预初始化只读取偏好，以避免已关闭状态刷新时闪烁；独立的页尾 `assets/js/sunlight.js` 负责启用按钮、切换状态和保存偏好。
- JavaScript 不可用时，效果保持默认开启，按钮维持 `hidden`，页面不会出现不能操作的假控件。404 不执行预初始化、不加载脚本，也不显示光层或按钮。

## 验证范围

- `tests/test_sunlight_contracts.py` 固化双语数据、页眉顺序、严格存储、渐进增强、视觉层与 404 边界。
- `tests/browser/sunlight.spec.mjs` 覆盖默认状态、键盘切换、刷新持久化、非法值、无 JavaScript、404、中英文文案、1280/390/320 px 光源对齐和横向溢出，以及欢迎页/文章页阅读层级。
- 生产构建继续通过 CSP、站点产物、旧 URL、翻译和缩略图检查；没有新增外部资源许可项。
