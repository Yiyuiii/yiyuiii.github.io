# 日光/月光背景与明暗主题实施规格

## 展示边界

- 除双语 404 外，所有默认布局页面都从左上角头像圆心发出环境光。明亮样式使用暖金日光；夜晚样式即时换为冷蓝月晕与更细、更稀疏的月光束，不继续显示黄色日光。
- 径向光晕由 `body::before` 绘制并在约 `58rem` 内淡出；光束由独立的 `body::after` 绘制，并以 `360s` 匀速完成一周极慢旋转。旋转层半径用 `clamp(21rem, 58vw, 46rem)` 响应视口，避免在高 DPR 手机上创建固定 `116rem` 的超大合成纹理。两层都不使用图片或滤镜、不接收指针事件，位于正文后的负层级，不改变布局、滚动或焦点。
- `prefers-reduced-motion: reduce` 会完全停止光束旋转，但保留静态日光或月光；关闭环境光时两个伪元素都不生成内容且动画停止。
- 光源坐标由页眉 `68rem` 最大宽度、页边距与 `2.25rem` 头像尺寸共同计算；在 1280、390、320 px 及移动页眉换行时仍与头像圆心一致且不产生横向滚动。

## 两个独立控件

- 页眉搜索与语言切换之间的外观按钮切换明亮/夜晚样式。它使用 `yiyuiii.theme.v1`，只保存 `light` 或 `dark`；默认 `light`，不隐式跟随系统主题。按钮图标显示下一步可切换到的月亮或太阳，动作与状态具有中英文 `aria` 文案。
- JavaScript 可用时，左上头像由返回首页链接渐进替换为环境光按钮；它使用既有兼容键 `yiyuiii.sunlight.v1`，只保存 `on` 或 `off`，默认 `on`。夜晚样式下同一按钮的动作和播报自动改称“月光”，但值域与职责仍只是环境光开关。
- 两个偏好互不读写：切换主题不改变环境光开关，切换环境光也不改变主题。非法值按各自默认值解释且不被静默改写；实现不使用 Cookie、访问记录、外部请求或其它追踪字段。
- 头像旁的 `yiyuiii` 文字始终链接当前语言欢迎页。JavaScript 不可用或环境光脚本失败时，头像本身仍是当前语言首页链接，两个按钮保持 `hidden`，页面维持默认明亮样式与静态可读的日光层。
- `<head>` 中的最小内联预初始化只读取两个偏好，以避免刷新闪烁；页尾 `assets/js/theme.js` 与 `assets/js/sunlight.js` 分别启用、切换和保存自己的状态。主题改变事件只让环境光按钮即时更新日光/月光名称，不交换偏好。
- 404 不执行偏好预初始化、不加载两个脚本，也不显示主题按钮、环境光按钮或任何光层。

## 色彩与可读性

- 明亮样式沿用纸白、墨色、紫晶与玉色体系。夜晚样式使用深墨绿黑页面、略亮表面、浅灰正文、浅紫晶与浅玉色；原生表单通过 `color-scheme: dark` 使用正确外观。
- 搜索框、代码块、对话框、卡片、分隔线、焦点环和正文颜色都读取主题变量。搜索框背景不得写死为白色，暗色正文与输入内容必须保持可读对比度。
- Mermaid 在初次载入时通过 `determineComputedTheme()` 读取预初始化主题；用户在阅读页切换主题后，`assets/js/theme.js` 用隐藏的原始 Mermaid 代码重新渲染 SVG，并恢复图形缩放，避免已生成图表滞留旧主题而失去可读性。重绘失败时恢复切换前 SVG。
- 月光层使用冷蓝、低透明度月晕，光束宽 `0.72deg`、每 `15deg` 一束；日光束宽 `1.35deg`、每 `10deg` 一束。两套参数集中在 `assets/css/main.scss`，不得按页面复制。

## 验证范围

- `tests/test_sunlight_contracts.py` 与 `tests/test_theme_contracts.py` 固化双语数据、两个严格独立存储键、头像无 JavaScript 回退、脚本职责、日光/月光参数、旋转与 reduced-motion、404 边界。
- `tests/browser/sunlight.spec.mjs` 覆盖默认状态、键盘切换、主题即时联动、刷新持久化、非法值、无 JavaScript、404、中英文动作/状态、暗色搜索框、1280/390/320 px 光源对齐与横向溢出，以及欢迎页/文章页阅读层级。
- 生产构建继续通过 CSP、站点产物、旧 URL、翻译和缩略图检查；没有新增外部资源许可项。
