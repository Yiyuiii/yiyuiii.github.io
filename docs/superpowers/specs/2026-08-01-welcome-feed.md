# 欢迎页与规范化内容流实施规格

## 已实施边界

- `/`、`/en/`：中英文欢迎页，`schema_type: WebSite`。
- `/writing/`、`/en/writing/`：中英文随笔索引，`schema_type: CollectionPage`。
- 品牌返回当前语言欢迎页；文章缺少译文时，语言切换回目标语言随笔索引。
- `_data/home.yml` 是欢迎页人工文案的唯一维护入口。
- `_data/home_feed.yml` 只保存稳定 ID、来源类型和来源引用，不复制内容详情或日期。

## 内容流契约

构建插件把随笔、项目和论文解析为 `id`、`kind`、`lang`、`title`、`summary`、`url`、`first_public_date`、`first_public_precision`、可选 `thumbnail` 与 `external`。日期不是首页清单中的人工排序值，而由各类内容自己的来源解析：随笔取 `revisions[0].date` 或文章 `date`；项目取经同步脚本核验的 GitHub `created_at` 香港自然日；论文取带来源 URL 和来源字段的最早权威公开记录。

近期公开 8 项严格按首次公开日期降序、同日 `id` 升序。当前结果由真实初稿、仓库创建和论文公开日期共同决定；后续修订、本站整理、普通仓库活动、Star/Fork、构建和错别字都不刷新日期。若未来只有年份证据，运行时保留 `year` 精度、页面只显示年份，并排在同年所有到日条目之后，不伪造 1 月 1 日。实现没有按类型补位，也没有 `featured`、`priority`、`score` 或隐藏权重。

面向访客的栏目名称为中文“随机发现”、英文 “Random discovery”，栏目说明为“每次进入随机抽取，不记录访问”。候选从中英文共同存在、并且不属于两种语言任一最近 8 项的身份中产生。客户端每次载入或刷新欢迎页时独立抽取，从浏览器 BFCache 恢复时也重新抽取；中英文页面不承诺同一身份，连续两次抽到同一项是允许的随机结果。

客户端使用 `crypto.getRandomValues()` 读取 32 位无符号随机数，并以拒绝采样排除无法被候选数整除的尾部区间，再安全取模，从而避免 modulo bias。实现不得改用 `Math.random`，也不读取日期，不读取或写入访问历史、Cookie、localStorage、sessionStorage、指纹，不发起外部请求。

脚本缺失、候选为空或安全随机源不可用时保留预渲染的固定“浏览起点”，该降级卡片不声称是随机结果。

## 页眉指引箭头实验与结论

语义指引始终以普通列表留在 DOM。曾在真实 production 构建上注入渐进式 SVG 箭头原型，只连接现有的品牌、导航、搜索和语言四类控件；没有为尚未合入的阳光开关伪造目标。原型使用 `pointer-events: none`，并按纯装饰、读屏隐藏的边界设计。

真实 Chrome 的 1280、390、320 px 验证结果分别为：4 条箭头均生成、无横向溢出，但每档箭头包围范围与欢迎标题/两段介绍发生 12 次几何相交。截图复核显示桌面长曲线穿过标题与介绍，390/320 px 曲线还穿越两行页眉和欢迎正文，明显增加阅读负担并产生误指感。

因此最终实现删除整个箭头视觉层，只保留欢迎页内的低对比度自然语言指引。当前五条指引分别说明：头像开关日光/月光、页顶文字切换栏目、全站搜索、中英文切换、页眉按钮切换明亮/夜晚样式；旁边的 `yiyuiii` 文字保留首页入口。欢迎页从未伪造按钮或交互目标，浏览器契约显式要求 `.home-guide-arrows` 不存在。所有指引继续只在 `_data/home.yml` 中人工维护。

## 渐进增强与兼容

- `/?tag=...` 在 JavaScript 可用时通过 `location.replace` 保留完整 query/hash 迁到当前语言随笔索引。
- GitHub Pages 无法按 query 做服务器重定向；无 JavaScript 时根页面仍完整可读，并通过 `<noscript>` 提供随笔索引入口。
- 欢迎页的 H1、指引、浏览起点和最近 8 项均为预渲染 HTML，脚本失败不会空白。
- 随笔图片只通过 `responsive-thumbnail.liquid` 和 160/320 px 派生图；欢迎页不加载原封面。
- 欢迎页设置 `math: false`，本地插件包装器使其不输出 MathJax 样式和脚本，文章仍保持原有数学支持。

## 验证范围

- Python 源码与数据契约覆盖文案集中、25 条来源完整性、严格字段、ID、首次公开日期及证据、解析、排序、路由、页眉和 MathJax 门禁。
- production Jekyll 构建后的站点检查验证欢迎页、8 条内容流、稳定排序、浏览起点、品牌路径、响应式图片和无 MathJax。
- Playwright 覆盖中英文随机发现文案、候选范围、最近项过滤、刷新与 BFCache 恢复重抽、拒绝采样、旧 tag query/hash、禁用 JavaScript、无原图请求及 1280/390/320 px 无横向溢出。
