# 随笔封面整理台账

更新时间：2026-07-31

本文档记录随笔封面的来源、授权、处理方式和当前状态。它是整理工作的事实台账，不代替文章修订档案。

## 当前采用的判断顺序

1. 先判断文章是否已有作者自己制作、截取或保存的正文图片可复用。
2. 若本地图片不能概括文章，或权利来源不清，再寻找能代表文章全局体验的真实图片。
3. 细分桌游优先寻找包含真实版图、骰子和组件的对局照片，不用无法还原具体游戏的生成图替代。
4. 每张外部图片必须记录作者、原始页面、精确许可、原始尺寸和许可是否允许裁切；“可以下载”不等于允许复用。
5. 需要裁切时不使用带 `ND`（禁止演绎）条款的图片。署名许可的图片在正文中保留可见署名，并在档案中记录原图与产物哈希。
6. 站点含有自愿 PayPal 捐助入口。`CC BY-NC` / `CC BY-NC-SA` 图片只能用于与捐助、广告、付费访问和商品销售无关的文章评论或索引展示，并在来源档案中记录这一用途边界；若网站商业模式变化，必须重新复核。能达到同等内容效果时，优先使用 CC0、CC BY 或 CC BY-SA。
7. 首页封面以方形构图为目标，但不为了填满方形而破坏图片主题；必要时更换候选。
