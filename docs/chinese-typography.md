# 中文文章排版基线

## 适用范围

本文记录本站中文随笔的排版依据与网页化取舍。它不是把学术出版或纸书规则原样搬到屏幕上，而是先区分规范中的稳定原则，再结合本站的字体、版心和响应式布局实现。

英文随笔遵循英文排版习惯；数学变量、物理量符号、拉丁学名及外文作品名等确有领域惯例的内容，不受“中文少用斜体”的一般规则覆盖。

## 主要依据

- W3C《[中文排版需求](https://www.w3.org/TR/clreq/)》将宋体、楷体、黑体、仿宋体列为中文排版的四类主要字体，并说明黑体常用于标题、图说和正文强调；中文强调也可以使用着重号。它还记录了中文出版物常见的两字段首缩排，以及正文行长、行距和标点禁则等原则。
- 国家新闻出版署发布的 CY/T 171—2019《[学术出版规范 插图](https://www.nppa.gov.cn/xxgk/fdzdgknr/hybz/202210/P020221004608860118669.pdf)》规定图号和图题一般位于图下，图题字号宜小于正文；图注字号宜小于图题或字体轻于图题，并要求同一出版物的图号、图题和图注体例一致。
- GB/T 15834—2011《[标点符号用法](https://std.samr.gov.cn/gb/search/gbDetailedCNF?id=71F772D7FE25D3A7E05397BE0A0AB82A)》和 GB/T 15835—2011《[出版物上数字用法](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=F5DAC3377DA99C8D78AE66735B6359C7)》目前均为现行国家标准。本站中文内容的标点和数字书写应以这两项标准为基础，再处理网址、代码、产品名等技术文本例外。

上述资料没有给出“所有中文一律禁止斜体”的绝对条款。本站采用的结论是：斜体源自西文排版，不能作为中文层级区分的默认工具；中文应优先通过字体类别、字重、字号、颜色、留白和着重号形成层级。

## 本站规则

### 正文与强调

- 中文正文保持直立字形和两字段首缩进；图片段、图题、列表、引用、代码、表格和显示公式不继承段首缩进。
- 普通强调优先使用字重、颜色或独立版式。不要为了套用英文视觉习惯而把整句汉字机械倾斜。
- 斜体只保留给具有明确语义或专业惯例的西文内容。不得用全局 `font-style: normal` 抹去数学变量、代码语义或英文页面中的合法斜体。

### 图题与图注

- 图题紧随图片之后，内容准确、简明；来源、许可和必要说明保持可见。
- 中文图题使用直立字形，取消段首缩进，以小于正文的字号、较轻的颜色和稳定的行距区分层级。
- 英文图题可保留英文斜体习惯，但与中文共用较小字号和次级颜色。
- 题图组件和正文图片采用同一中文原则。正文中“图片段之后、仅含一个 `em` 的段落”是当前旧稿图题的结构标记；样式必须同时验证结构关系和语言，不得把所有中文 `em` 一概改为直立。

### 标点、数字与混排

- 中文句子使用中文全角标点；完整英文句子、代码、网址和机器标识符保留其自身标点规则。
- 数字、日期、计量单位和范围符号应在同一文章内保持一致。数学和物理符号的正斜体服从领域规范，不以视觉偏好替代语义。
- 中西文混排、不可断行的英文词和标点避头尾问题，应优先用网页布局规则解决，不在内容中插入不可维护的手工空格或换行。

## 验证边界

- 浏览器回归分别检查中文正文图题为直立、字号小于正文、颜色不同且无段首缩进，并检查英文图题仍保留英文斜体。
- 题图组件单独检查中文图题不为斜体。
- 后续若引入正式的正文 `<figure>/<figcaption>` 组件，应以语义元素替换当前旧稿结构标记，并同步更新本文件和回归测试。
