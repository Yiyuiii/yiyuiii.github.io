# “名画一瞥”AIC 实时接入可行性核验（2026-08-05）

## 结论

当前不实现，也不加入“小玩意”入口。

AIC 馆藏元数据侧满足无密钥、单次随机小批次和跨域读取要求，但官方 IIIF 图片地址在真实 Chromium 会话中返回 HTTP 403，并进入 Cloudflare 页面级人机验证。`<img>` 热链不能完成这种验证，因此无法保证本局四张候选图可显示。该失败触及玩法的核心媒体路径，不能用固定本地图片池、代理、重试或其它第三方镜像绕开。

## 原型边界

核验严格遵守项目现有约束：

- 不申请或传递 API 密钥；
- 不下载馆藏索引、ID 全表或本地题池；
- 不保存外部响应或图片；
- 不追随分页，不因筛选失败追加批次；
- 只验证官方 AIC API 与官方 IIIF 地址；
- 实际请求控制为三个小批元数据请求和两个针对同一已判定公共领域作品的图片访问尝试。

若媒体路径可用，拟议的单局预算原本可以固定为：

1. 一次 `GET /api/v1/artworks/search`，取得 24 件随机公共领域绘画的必要元数据；
2. 四个本局候选的 400px 官方 IIIF 图片请求。

线索局部和完整候选可以复用同一批四张图片，以 CSS 裁切切换显示，不需要第五张媒体请求。所有数据只留在页面内存；重新开始才由玩家触发下一组请求。

## 官方依据

- [AIC API 文档](https://api.artic.edu/docs/)说明公开 API 无需项目密钥，搜索端点接受 Elasticsearch Query DSL，并支持 `is_public_domain=true`、分页与字段选择。
- 同一文档建议对公共领域作品使用官方 IIIF Image API 并直接热链，同时提醒 IIIF 端点也可能包含非公共领域图片，使用方必须逐件判定。因此原型只接受元数据中同时具有 `is_public_domain=true` 与非空 `image_id` 的记录。
- [AIC Open Access Images](https://www.artic.edu/open-access/open-access-images)和[图片许可页](https://www.artic.edu/image-licensing)说明带有 “CC0 Public Domain Designation” 的开放图片按 CC0 提供。
- [AIC Terms](https://www.artic.edu/terms)允许使用明确标作 CC0 的图片与数据；这不替代逐件公共领域检查。

## 实时证据

### 元数据路径：通过

使用加密随机种子，把 Elasticsearch `function_score.random_score`、公共领域过滤、`image_id` 存在过滤和绘画类型过滤放在同一次搜索请求中。有效查询返回：

- HTTP 200；
- `Access-Control-Allow-Origin: *`；
- 24 条结果；
- 24 条均为 `is_public_domain=true`、具有 `image_id` 的绘画；
- 24 个题名互不重复；
- 当前过滤结果总量为 2,095。

这证明无需先请求总数、下载 ID 清单或随机翻页，就能在一次元数据请求中取得足够候选。一次早期字段选择试验和一次大小写不匹配的精确类型过滤也分别返回 HTTP 200；它们只用于确定官方查询语法，没有产生媒体下载或后续抓取。

### 图片路径：未通过

对上述同一批次中一件已判定为公共领域的作品，只请求官方文档推荐模式的 400px IIIF JPG：

```text
https://www.artic.edu/iiif/2/{image_id}/full/400,/0/default.jpg
```

结果：

- PowerShell 的直接 HTTPS 请求收到 Cloudflare 验证 HTML，而非图片；
- 使用真实 Chromium 直接打开同一 URL，页面标题为“请稍候…”，HTTP 状态为 403；
- 浏览器快照显示“正在进行安全验证”，并产生控制台错误；
- 没有取得或保存图片文件。

Cloudflare 验证需要页面脚本与 Cookie 状态。作为第三方页面中的 `<img>` 子资源时，返回的验证 HTML 不会转化为可玩的图像；即使部分读者已有有效验证状态，也不能据此承诺普通访问稳定可用。

## 未继续验证的项目

媒体主路径已失败，所以没有继续增加网络样本，也没有开展以下内容：

- 四张并发图片的成功率、总字节数与延迟；
- 裁切可辨识度、题名或文字直接入画、敏感内容审计；
- 移动端布局、键盘流程和固定桩浏览器测试；
- 双语文案、组件、脚本和共享入口集成。

这些工作不能改善核心图片 403，继续请求只会增加无效外部流量。

## 重新评估条件

只有满足以下任一条件才应重启：

1. AIC 提供并正式文档化不经过页面级人机验证、允许第三方 `<img>` 热链且继续逐件标示 CC0 的媒体主机；
2. 官方 IIIF 地址在本站正式域名、普通无登录浏览器和目标访问地区中，经多时段小样本验证均能直接返回图片，并且不要求本站代签、密钥或持久 Cookie。

重启时仍必须保持“一次元数据请求 + 四张本局候选图”、无续页、无预取、无本地题池，并在开始前披露 AIC／Cloudflare 可看到请求、来源页和 IP 地址。
