# 《工业革命：匹兹堡》规则随笔审计（2026-08-10）

## 用户原始要求

- 结合《SETI》规则随笔的写作与审计经验，新增《工业革命：匹兹堡》随笔教学。
- 教程应让读者按真实摆桌和游玩顺序完成第一局，规则链优先于历史背景或策略评论。

## 当前官方材料与版本边界

- [Roxley 产品与下载页](https://roxley.com/products/brass-pittsburgh)将当前规则文件列为 `2026.06.01`。
- [规则书 PDF](https://cdn.shopify.com/s/files/1/0246/2190/8043/files/Brass-P-Rulebook-ENG.pdf?v=1775836834)页脚写作 `Rulebook v2026.01`，共 6 个横向跨页、对应印刷页 2–11。
- [Gamefound 规则书发布说明](https://gamefound.com/en/projects/roxley/brass-pittsburgh/updates/28)把它称为接近完成的草稿，明确粉色文字未定稿、只覆盖 2–4 人、单人模式仍在开发、翻译待规则完全定稿后提供。
- 规则书印刷页 3 的八个人物说明仍使用重复日期与占位文案；本文不把这些内容当作历史事实。

结论：文章只教授当前稿已写明的 2–4 人流程，并在开头和速查中保留版本警示。后续正式规则发布时，需要重新核对数值、图标、术语、单人模式、人物介绍和全部粉色文字。

## 从《SETI》沿用的教学结构

| SETI 经验 | 本文落点 |
| --- | --- |
| 先限定范围和来源 | 首节同时说明下载页日期、PDF 页脚版本和草稿状态 |

| 用完整首轮验证规则可执行 | 三人首轮串起地点牌建造、共享产业资源、第一条铁路、贷款、轮末顺序与收入 |

## 当前稿需要保留的待复核点

1. 下载页日期与 PDF 内版本号不一致；后续按文件内容哈希和官方最新链接重新判断，不根据当前命名猜测。
2. 规则书人物页为占位稿；本文没有转述任何粉色传记内容。
3. 当前规则没有单人模式；文章不新增“照多人执行”的自创裁定。
4. 资源页把产业设为强制第一优先级，最后一页对照表把个人资源重轨、市场与范德比尔特列在同一后续层级；正文按这条闭环表达。
5. 出售页写明从连通油田经管线取油，资源重轨页又允许按原油运输规则使用车上原油；正文以“直接从油田取油必须走管线、车上原油按板块特例”区分来源。
6. 规则仍可能调整数值和图标。正文避免把人物页、占位文案或版面错误推导成稳定事实。
