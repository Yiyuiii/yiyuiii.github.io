## 先说明这组图怎样使用 {#assign-roles-before-choosing-products}

这篇随笔最初是一页可以随时翻看的视觉备忘录：同一个人换上不同颜色的外套，我能迅速想起每种颜色怎样改变全身，以及它能否与现有衣服连接。旧稿只剩一张衣架题图以后，文章最有用的部分也随之消失。这次重写先恢复这个用途，再补上能实际约束购买的验证方法。

正文的五张穿搭图均由 OpenAI `image_gen` 生成。模特是虚构人物，不代表作者；服装不对应在售商品。生成过程尽量锁定人物、姿势、镜头、背景和光线，但 AI 仍可能留下细小差异。图组适合比较画面内部的相对关系，不能替代实物试穿。

| 图组 | 固定的条件 | 有意改变的条件 | 可以回答的问题 |
|---|---|---|---|
| 四色综合对照 | 模特、姿势、镜头、光线、内搭、裤子、鞋、外套版型 | 只改外套颜色 | 同一套衣服怎样被四种颜色重新组织？ |
| 每种颜色的双穿搭 | 模特、镜头、光线、该组外套颜色与版型 | 内搭、下装，必要时改变鞋 | 同一件外套怎样进入两种常见配色方向？ |

国际照明委员会的 [CIECAM16 色貌模型](https://www.cie.co.at/publications/cie-2016-colour-appearance-model-colour-management-systems-ciecam16)需要把观看条件和色适应纳入计算。本文的摄影棚光、屏幕显示、面料纹理和你的实际环境都不相同，因此图中的颜色只能作为记忆锚点。生成提示使用的 sRGB 目标是砖红 `#984737`、暖米色 `#C2A77D`、橄榄绿 `#66683D` 和炭灰 `#3C4043`；这些代码记录本组图的制作意图，不定义商品颜色。

## 四种颜色先各承担一个视觉任务 {#what-the-four-colors-do}

这四种颜色来自我的衣橱需求，不是人人都需要照抄的基础清单。我先给它们分配不同任务，再看一件具体外套能否完成任务。这样可以避免把多个相近色名误当成多个真实缺口。

| 颜色 | 这组图里的主要任务 | 最容易开始的现有衣物 | 需要留意的失败信号 |
|---|---|---|---|
| 砖红 | 在低饱和组合中提供暖色焦点 | 暖白、炭灰、深蓝、牛仔蓝、米色 | 内搭、鞋和配件也很醒目，视觉重点互相竞争 |
| 暖米色 | 提高全身明度，让浅色与自然色之间有过渡 | 浅蓝、白、炭灰、牛仔蓝、橄榄绿 | 与肤色或背景接近不等于失败；面料、轮廓和清洁状态更容易暴露 |
| 橄榄绿 | 在中性色与明显彩色之间提供低饱和过渡 | 暖白、牛仔蓝、炭灰、棕、低饱和红 | 军绿、苔绿、灰绿外套名称不同，实际用途却完全重叠 |
| 炭灰 | 提供深色边框，让内搭决定正式度与色彩方向 | 浅蓝、暖白、深蓝、橄榄绿、低饱和暖色 | 与黑色或深灰外套在长度、温度和场景上没有新增用途 |

先记住四句即可：砖红负责焦点，暖米色负责提亮，橄榄绿负责过渡，炭灰负责收束。下面的双穿搭再说明这些任务如何落到具体衣服上。

## 砖红：让其它大色块安静下来 {#brick-red-one-focal-point}

在图 1 的统一条件下，砖红是上半身最明显的彩色块。这个观察只针对当前图组；它说明砖红可以承担焦点，不证明所有人都偏好这种效果。

![同一位模特穿同一件砖红短工作外套的两套搭配：左侧为暖白针织衫、深靛蓝牛仔裤和深棕鞋，右侧为炭灰针织衫、暖米色长裤和深棕鞋](/assets/posts/202608081100/outerwear-brick-red-pairings.webp)

*图 2｜砖红的两种入口。左侧用暖白和深靛蓝形成清楚的明暗分区；右侧用炭灰压低内搭存在感，再以暖米色下装接住外套的暖意。模特、外套、镜头和光线固定。AI 生成示意图。*

左侧更接近我最容易复用的日常组合：暖白给砖红留出边界，深靛蓝牛仔裤让下半身保持稳定。右侧的颜色更集中在暖色范围，炭灰内搭仍然把外套留作主要焦点，暖米色长裤则减少上红下黑的硬切割。

砖红外套如果必须依赖一条新裤子、一双特定鞋或一套完整造型才成立，它就没有改善现有衣橱。购买前应先拿最常穿的深色下装、最难搭的浅色下装和两双高频鞋试穿；只能成功一套时，我会把它归入场合服装，而不是日常主力。

## 暖米色：用内搭和下装重新画出边界 {#beige-is-about-lightness}

暖米色的作用不只是“百搭”。它提高上半身明度，同时把面料纹理、领口、口袋和污渍变得更容易看见。同一个米色落在挺括棉布、绒面或羊毛上，会表现出不同的季节和正式度。

![同一位模特穿同一件暖米色工作外套的两套搭配：左侧为浅蓝衬衫、炭灰长裤和深棕鞋，右侧为橄榄绿针织衫、中蓝牛仔裤和米白鞋](/assets/posts/202608081100/outerwear-warm-beige-pairings.webp)

*图 3｜暖米色的两种边界。左侧由浅蓝衬衫提供轻微色相差，炭灰长裤压住下半身；右侧把橄榄绿与中蓝牛仔放在同一低饱和范围，米白鞋延续浅色。AI 生成示意图。*

左侧适合需要稍整齐轮廓的日子：外套、衬衫和裤子有清楚层级，又没有依赖强烈撞色。右侧更接近日常休闲，橄榄绿内搭不会退化成完全无色的背景，中蓝牛仔也比深黑下装柔和。

暖米色候选需要同时通过颜色与维护测试。在自然光下查看它是否偏黄、偏灰或偏粉，再检查领口、袖口和口袋边是否容易留下痕迹。衣柜里已有卡其或浅棕外套时，新候选至少要在长度、面料、温度范围或正式度上增加一项真实用途。

## 橄榄绿：控制饱和度以后，可以连接冷暖两边 {#olive-between-neutral-and-character}

橄榄绿常被商品页拆成军绿、苔绿、卡其绿、森林绿或灰绿。名称不能证明衣橱用途不同；真正影响组合的是明度、偏黄或偏蓝、面料光泽、轮廓与已有衣物的关系。

![同一位模特穿同一件橄榄绿工作外套的两套搭配：左侧为暖白针织衫、深靛蓝牛仔裤和深棕短靴，右侧为低饱和砖红针织衫、米白长裤和深棕鞋](/assets/posts/202608081100/outerwear-muted-olive-pairings.webp)

*图 4｜橄榄绿的两种方向。左侧以暖白和深靛蓝构成安静基础；右侧同时使用低饱和砖红与橄榄绿，再用米白下装拉开两个彩色层次。AI 生成示意图。*

左侧是低风险组合，适合判断一件橄榄绿外套能否进入现有牛仔衣橱。右侧保留两个彩色层，但两者饱和度都不高，米白下装又给它们留下空间；如果实物中的红更亮、绿更鲜或面料反光更强，画面的平衡会随之改变。

结构较多的工装、猎装或短派克很适合承载橄榄绿，前提是口袋、抽绳、肩章和金属件没有同时制造过多重点。已有相近绿色外套时，应直接把两件放进同一套高频衣服里比较；新候选没有增加可穿组合，就只是在替换色名。

## 炭灰：让版型和内搭决定正式程度 {#charcoal-lets-silhouette-carry-change}

图 1 用同款短外套隔离颜色变量；下面改用较长羊毛大衣，是为了展示炭灰在我的衣橱里承担的实际用途。两张图回答的问题不同：前者比较颜色，后者比较同一件长外套如何进入两个场景。

![同一位模特穿同一件炭灰长羊毛大衣的两套搭配：左侧为浅蓝衬衫、深蓝长裤和黑色德比鞋，右侧为暖白针织衫、橄榄绿长裤和深棕短靴](/assets/posts/202608081100/outerwear-charcoal-pairings.webp)

*图 5｜炭灰长外套的两种正式度。左侧以浅蓝、深蓝和黑鞋形成较清晰的通勤线条；右侧以暖白、橄榄绿和棕靴降低正式感。模特、大衣、镜头和光线固定。AI 生成示意图。*

炭灰比纯黑更容易在柔光中保留羊毛纹理，也能让浅蓝、暖白、橄榄绿或低饱和暖色决定画面方向。左侧的深色下装延续大衣的纵向轮廓，右侧的橄榄绿长裤则把深色外套带回日常。

购买深色外套时，要在自然光下确认它偏蓝、偏棕还是接近黑，并与常穿黑裤、深蓝裤和鞋一起看。商品页的统一曝光会压缩深色差异。已有黑色长大衣时，新的炭灰大衣还需要在保暖、重量、活动量或正式度上解决另一个问题。

## 为什么不把它写成一套万能配色规则 {#four-filters-after-color}

Schloss 与 Palmer 的[受控色块实验](https://pmc.ncbi.nlm.nih.gov/articles/PMC3037488/)区分了三件事：是否喜欢整组颜色、是否觉得它们和谐，以及前景色是否突出。三种判断受色相相似、单色偏好与明度对比影响的方式不同。把“协调”“喜欢”和“醒目”写成同一个结论，会让穿搭建议失去边界。

服装研究也没有给出一张永久有效的色轮答案。Zhang 等人的[时装配色兼容研究](https://arxiv.org/abs/2007.02388)指出，手工色相模板会偏离用户数据，完整穿搭也不能稳定地化约为若干两两配色。数据本身仍会携带平台、年代和流行偏差，因此本文选择一条较小但可复核的结论：先用图形成候选，再让你的现有衣物、场景和使用记录决定去留。

## 用“新增可穿组合”测试一件外套 {#use-slots-to-limit-duplicates}

Hsiao 与 Grauman 的[胶囊衣橱研究](https://openaccess.thecvf.com/content_cvpr_2018/papers/Hsiao_Creating_Capsule_Wardrobes_CVPR_2018_paper.pdf)把目标拆成兼容性、用途覆盖和个人偏好，并强调新增一件衣物会同时带来多套可能组合。对个人衣橱最有用的借鉴是计算**新增可穿组合**，不计算商品页上想象出来的“百搭”。

我会先固定一小组真实样本：两件高频内搭、一件最难搭的内搭，三条常穿下装和两双高频鞋。它们最多形成十八套理论组合，但只有同时满足以下条件的组合才计数：

- 不购买新的内搭、下装、鞋或配件即可完成；
- 坐下、抬手、步行、背包和加常用内层后仍然舒适；
- 对应未来一个月确实会出现的天气与场景；
- 我愿意直接穿出门，而不只是承认照片“没有问题”；
- 现有外套不能以同样效果覆盖，或者新候选明确替换其中一件。

记录时可以使用下表；失败原因比一个总分更有用：

| 实际组合 | 场景与天气 | 舒适和活动 | 无需添购 | 现有外套能否替代 | 是否新增 |
|---|---|---|---|---|---|
| 内搭 A + 下装 A + 鞋 A | 例如：日常通勤，12–18°C | 通过／失败原因 | 是／否 | 能／不能 | 是／否 |
| 内搭 B + 下装 B + 鞋 A |  |  |  |  |  |
| 内搭 C + 下装 C + 鞋 B |  |  |  |  |  |

我的个人停止线是：至少三套不添购即可穿的组合，覆盖两个真实场景，其中至少一套是现有外套无法提供的新组合。这个数字不是研究结论；重要的是在浏览商品前写下停止线，避免看到喜欢的单品后临时降低标准。

## 把生成图换成自己的快速回忆卡 {#make-a-personal-outfit-memory-card}

生成图适合找方向，最终应该由自己的衣服和身体接管。完成试穿后，可以用手机做一张更可靠的个人回忆卡：

1. 选择同一面墙、同一扇窗和相近时段，关闭滤镜；手机允许时固定曝光与白平衡。
2. 相机高度、站姿、距离和全身裁切保持不变，每次只换一组明确变量。
3. 每件候选外套至少拍最常穿、最难搭、稍正式和对应天气的组合；不适用的场景直接跳过。
4. 在图片外记录内搭、下装、鞋、温度、场景和失败原因，不在照片上依赖模糊的“好看／不好看”标签。
5. 穿着四周后删去从未真实使用的组合；剩下的照片才是下一次购买前值得翻看的图谱。

这张个人卡会逐步替代本文的 AI 图。它保留同样的比较纪律，同时加入你的体型、动作、生活场景和真实衣物。

## 购买前完成实物复核 {#a-practical-decision-card}

WRAP 与 Leeds Institute of Textiles and Colour 的[服装耐用研究](https://www.wrap.ngo/resources/report/durability-fashions-next-competitive-advantage)发现，价格、品牌和纤维成分都不能单独预测耐用性，耐用需要实际测量。个人试穿无法完成实验室测试，但可以提前排除明显不适合高频使用的候选。

- [ ] **颜色**：在自然光、室内常用光和阴影里观察，并与常穿裤子、鞋放在一起；
- [ ] **版型**：检查肩线、袖长、衣长和叠穿容量，确认与已有外套存在真实差异；
- [ ] **动作**：坐下、抬手、伸手、步行、背包和扣合以后仍然舒适；
- [ ] **结构**：检查拉链、纽扣、缝线、口袋、里布和高摩擦位置，只把它当作明显缺陷筛查；
- [ ] **维护**：确认洗护标签、粘毛、起球、污渍、防雨、晾晒和收纳要求符合预期频率；
- [ ] **组合**：达到预先写下的新增可穿组合停止线；
- [ ] **替换**：若用途重叠，先明确替换对象，并在试穿期结束后再决定旧衣去留。

这四种颜色最终只是我的起点。文章真正要保存的是一套工作方法：固定条件看差异，用实际衣橱算新增组合，再让自然光、动作、维护和真实穿着记录推翻不成立的想象。这样留下来的外套才更可能从“单件很好看”变成经常会穿的衣服。
