小玩意

几个随时可以展开、用完即走的轻量互动。

萌娘百科角色猜猜 阅读匿名化的条目导言，从四个候选中找出角色。

点击开始后，本页只会向萌娘百科 API 请求一次随机条目的纯文字导言与分类，并在浏览器本地筛选本题；第三方可看到本次请求和你的 IP 地址。本站不使用 Cookie、持久化存储或跟踪，也不请求图片。

匿名线索

线索取自一个随机发现条目的导言；可识别的角色名片段会替换为 ⬛。

线索是上方来源条目的匿名化节选；条目文本按来源页标示的许可协议提供，再次使用时请保留来源与署名。 查看 CC BY-NC-SA 3.0 协议

轻松挑战

色差挑战 找出颜色略有不同的方块，看看你能走到第几关。

每三题结算一次：答对至少两题升一级，否则降一级，共 25 级。每题答对加 1 分、答错减 1 分，因此积分可以为负。

难度从黑白最大数字色差延伸到 sRGB 单通道相差一个码值。这是视觉小游戏，不是色觉检查或医学评估。
